ChestDrop - Minecraft 1.21.4 Fabric

What it does:
- Adds a "Drop All" button beside vanilla chest/barrel container screens.
- Clicking it drops the complete stack from every non-empty container slot.
- It does NOT empty the player's inventory.

Important:
This is a separate addon, because Fast Get does not provide its source code.
You can use this alongside Fast Get.

Build:
1. Open this folder in IntelliJ IDEA.
2. Import/sync it as a Gradle project.
3. Use JDK 21 for Gradle.
4. Run the Gradle task: build
5. The finished JAR will be in build/libs/

Install:
Put the generated chestdrop-1.0.0.jar into .minecraft/mods.
Fabric API is also required.
